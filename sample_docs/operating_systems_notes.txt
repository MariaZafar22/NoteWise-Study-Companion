Operating Systems - Lecture Notes

A process is a program in execution. It has its own memory space, program counter and resources. A thread is a lightweight unit of execution inside a process. Threads of the same process share the same memory, which makes communication fast but also makes synchronisation important.

CPU scheduling decides which process runs next. First Come First Served is simple but short jobs can wait behind long ones. Shortest Job First gives the lowest average waiting time but can starve long jobs. Round Robin gives each process a fixed time quantum, which makes it fair and suitable for time-sharing systems.

A deadlock happens when a group of processes wait for each other forever. Four conditions must hold together: mutual exclusion, hold and wait, no preemption and circular wait. Breaking any one of these conditions prevents deadlock. The Banker's algorithm avoids deadlock by granting a resource only if the system stays in a safe state.

Paging is a memory management technique that divides physical memory into fixed-size frames and logical memory into pages of the same size. A page table maps each page to a frame. Paging removes external fragmentation, but a small amount of internal fragmentation can occur in the last page. Virtual memory uses paging so a program can be larger than physical RAM, and a page fault occurs when a needed page is not in memory.
